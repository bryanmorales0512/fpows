========================================================================
 FPOWS — Requirements & Setup (developer reference)
========================================================================

NOTE: This is a Node.js project, not a Python project. The authoritative
dependency manifest is package.json + package-lock.json. This file is a
human-readable summary; to actually install everything, run:

    npm install

------------------------------------------------------------------------
 System prerequisites
------------------------------------------------------------------------
Node.js        >= 20   (project targets Node 20; tested on Node 24)
npm            >= 9    (ships with Node)
git            any recent version

Optional (only for deploying to Google Cloud Run):
gcloud CLI     authenticated (`gcloud auth login`)
Docker         Desktop/Engine (deploy.ps1 uses it; falls back to Cloud Build)

------------------------------------------------------------------------
 First-time setup
------------------------------------------------------------------------
1. npm install
2. Copy .env.example -> .env and fill in credentials
   (see README.md "Environment Variables")
3. npm start          # http://localhost:3000
   npm run dev        # auto-reload during development
